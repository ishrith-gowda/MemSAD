**W1 — threat model.** Agreed the meaningful threat is cross-principal; we will lead with it. Cases: (1) shared/multi-tenant memory — one principal (or a compromised account) writes entries a different principal's session retrieves; (2) tool-output ingestion — the agent writes untrusted web/email/document content into memory; the attacker controls the content, not the agent (the dominant vector, no write access needed); (3) MINJA (query-only) and INJECMEM (single-interaction) are different-principal by construction. WRITE (Def 2–3) is the worst-case adversary used to state the strongest guarantee; we will label it as such. The certificate is deterministic precisely in the cross-principal case (a legitimate victim issues in-distribution queries) and weakens only for same-principal self-poisoning — which, as you note, is not a meaningful threat. So the assumption holds where the threat is real.

**W2 — overclaiming.** Agreed. We correct "regardless of adversary strategy" to: holds for continuous perturbations under Assumption 9 (typical query). It does not cover a colluding user crafting an atypical query, nor discrete synonym substitution (Prop 13). We present the triggered-calibration operating point explicitly, not as universal coverage.

**W3 — hardness irrelevant if greedy synonyms win.** Agreed; we do not claim the hardness result defends against greedy substitution. Prop 15 (CVP) characterizes the worst-case *optimal unconstrained-token* evasion: gradient coupling (Thm 7) closes the continuous surface, the CVP reduction closes the unconstrained-token surface, leaving the low-perturbation synonym regime as the residual gap — exactly the frontier Prop 13 identifies and we report (80–100% evasion, ΔASR-R≈0). We will foreground this. New: the certified synonym radius is encoder-dependent (r*≥1 under mpnet vs 0 under MiniLM; a max-over-encoders detector gives r*≥1 for a majority), partially mitigating it.

**Q — SINGLE access, |P|=1 vs 15 entries.** Wording ambiguity we will fix. "|P|=1" means one *interaction* (one write episode), not one entry; within that interaction INJECMEM writes 3×n_base=15 broad-anchor entries from 8 templates (lines 257–264). We will restate Def 2 as "a single adversarial interaction that writes |P|≥1 entries"; the threat-model results use the per-interaction definition.
